# 知序 SIGNAL

黑白编辑刊物风格的中文 AI 资讯精选网页。2026-09-05 核验快照，共 8 条，原始发布日期覆盖 2026-08-26 至 2026-09-04。

## 预览

直接打开 `index.html`，或执行 `node server.cjs` 后访问 http://127.0.0.1:4173 。无需安装依赖。

## 已实现

- 八条资讯的发布日期、背景、内容、直接来源链接与逐条核验说明。
- 六家机构筛选、关键词搜索、时间排序、知乎线索视图、浏览器本地收藏及空状态。
- 响应式桌面与移动页面、键盘焦点、搜索快捷键 `/`、核验说明弹窗。
- 社交渠道真实覆盖说明；微信公众号未直连核验，微博本期没有收录。

## 核验和更新

所有入选信息均回溯官方原文。MHS 同时保留知乎线索；不把转载日期当作事件日期，不把厂商跑分当作独立测试结果。百度文章正文主要是图片，本期内容仅取官方列表的可验证文字与产品链接。

文章存储于 `index.html` 的 `article-data` JSON 区块。更新时先核验发布方身份、原文日期、产品名称、可用范围和关键主张，再修改 JSON、期号、核验日期、覆盖日期及数量。每期保持 5–8 条，无法核验的内容不进入已核验列表。

当前是静态网页与已核验内容快照，未实现自动采集、自动事实核查或定时发布。不要将刷新页面理解为重新抓取最新新闻。没有外部分析脚本、API 密钥或后端数据库；收藏仅保存在当前浏览器。

## GitHub Pages 发布

目标仓库： https://github.com/Shawnnn/ai_news 。发布工作流位于 `.github/workflows/pages.yml`，仅打包 `index.html`，不发布本地脚本、截图或内部实施文档。

首次发布需在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions。将网页和工作流推送至默认分支（main 或 master）后，工作流会部署网站；也可在 Actions 中手动运行 Publish AI News。以后修改 `index.html` 并推送会自动更新网页，新闻内容仍需单独采集与核验。

默认地址预期为 https://shawnnn.github.io/ai_news/ ，须以成功部署后的 Pages 实际地址为准。当前本地准备配置不代表已经上线。
